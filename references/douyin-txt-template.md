# 抖音发布 TXT 模板（期目录单文件素材包）

文件名固定：`抖音发布文案.txt`，写在用户期目录根下。**不生成视频/封面副本**——用户发布时直接用期目录原视频。

## 模板

```text
抖音发布文案（电脑浏览器手动发布用）
========================================

【标题】（直接复制）
<标题，≤30 字，贴视频封面卡花字>

【描述】（含话题，整段复制粘贴，话题会自动联想）
<口播终稿浓缩版，观点不改，150 字内>
#<话题1> #<话题2> #<话题3> #<话题4> #<话题5>

【搜索关键词】（选题参考，不用发布）
<词1> / <词2> / <词3> / <词4> / <词5>

【备注】
竖屏 <时长> <分辨率> <帧率>，电脑浏览器发布。发布后 2 小时看播放来源出现「推荐」= 通道正常。

【发布步骤】（电脑浏览器手动发布）
1. 打开你平时用的浏览器（不要用自动化/无痕窗口），登录 creator.douyin.com
2. 上传本目录「<原视频文件名>」
3. 粘贴上方描述（话题自动联想后逐个确认）
4. 封面用视频帧即可
5. 发布后 2 小时看播放来源：出现「推荐」= 通道正常
```

## 写作规则

1. **标题 ≤30 字**（抖音硬限），优先沿用视频封面卡花字——用户自制封面卡与标题一致
2. **描述 = 口播终稿浓缩**：观点一字不改，删冗余语气词；敏感词命中时按词检结论处理（用户拍板）
3. **话题 4-5 个**：绑定当期主题词 + 垂类大词；话题名必须与内容实际相关
4. **搜索关键词**：真实用户会搜的问句式短语，仅作选题参考不发布
5. 小红书同内容标题另算：**≤20 字**（平台硬限），不要复用抖音 30 字标题
6. 发布步骤保持「电脑浏览器手动」口径——**任何自动化工具碰抖音都会被抑制推荐（历史实锤），此规则永久**
